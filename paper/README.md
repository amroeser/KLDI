# Paper data: *From Detection to Provenance*

This folder contains the data and results of the experimental run reported in the paper
(run `510b28a7-c573-4002-8304-2295872f5d6c`, executed 2025-12-09, `gpt-4.1-mini`,
temperature 0.10, seed `1475987267`). It was exported from the application database
(`data/app.db`, not included) with `scripts/export_from_db.py`.

## Contents

| File | Content |
|---|---|
| `data/source_passages.csv` | 500 human-written source passages (domain, source URL, retrieval time, text, SHA-256) |
| `data/selected_paraphrases.csv` | The selected (minimum-KLDI) `gpt-4.1-mini` paraphrase per passage |
| `data/human_human_pairs.csv` | The 200 within-domain Human→Human reference pairs (first 50 unordered pairs per domain in `(domain, id)` order) with their KLDI |
| `results/human_ai_scores.csv` | Human→AI KLDI per passage (`kldi` = `kldi_best`, `kldi_initial`, number of accepted candidates, token lengths, classification) |
| `results/run_summary.json` | Full statistical summary as stored by the pipeline |
| `results/run_config.json` | Run configuration (model, temperature, seed, KLDI settings) |
| `results/run_report.md` | Markdown report generated by the application for this run |
| `scripts/kldi.py` | Stand-alone KLDI implementation identical to `paraphrase_agents/evaluator.py` |
| `scripts/reproduce_stats.py` | Recomputes every number reported in the paper from the CSV files |
| `scripts/export_from_db.py`, `scripts/redact.py` | Export from the database and creation of this public release |

## Reproducing the results

```bash
pip install numpy scipy scikit-learn nltk
python -c "import nltk; nltk.download('punkt_tab')"
cd paper/scripts
python reproduce_stats.py
```

Expected output (bootstrap CIs may differ slightly, because the original run used an unseeded RNG):

```
T_adaptive (Q3 + 1.5*IQR of H->H): 63.358
H->AI above threshold: 0 / 500
Mean KLDI  H->AI: 12.489   H->H: 21.016
Mann-Whitney U p: 2.365e-23
ROC-AUC: 0.259   inverted: 0.741
Cliff's delta (H->H vs H->AI): 0.481
```

## Notes on the data

- **KLDI is computed over word bigrams.** `KLDEvaluator` uses its default `n=2`: NLTK
  `word_tokenize` on lowercased text, then adjacent token pairs. Base-2 logarithm,
  ε = 1e-10 smoothing on Q, direction P‖Q (source ‖ paraphrase). All stored scores are
  reproduced exactly with these settings.
- **Repeated passages.** The 500 passages contain 170 distinct texts, because the same
  snippet could be selected from a source more than once. The column `identical_text`
  in `human_human_pairs.csv` marks the 44 reference pairs with identical texts (KLDI ≈ 0).
- **Not retained.** Non-selected paraphrase candidates, retry-level diagnostics and the
  API call history were not stored and are not available.

## Copyright and redacted texts

Passages were scraped from the public sources listed in Appendix B of the paper. Texts
from Project Gutenberg, U.S. government sites, EUR-Lex, Gesetze im Internet, WHO, CDC and
ECDC are included in full with their source URL.

The texts of **48 news passages** (archived BBC/The Guardian pages via `web.archive.org`)
and **27 medical passages** (`chlaep.org.uy`) are subject to third-party copyright or an
unclear licence. They are **not redistributed** here: in `source_passages.csv` and
`selected_paraphrases.csv` their text fields are empty and `text_redacted = 1`. URL,
domain, all KLDI scores and the SHA-256 hash of the original text remain available, so
every statistic can still be recomputed. The full texts are available from the authors
on reasonable request.

All excerpts are short (80–220 characters) and were used solely for scientific text and
data analysis.
